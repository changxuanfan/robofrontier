# Lifted Horizontal Spring-Dial Module · two-arm scene

A red spring-return knob sits on top of a thin, horizontal white dial disk. A long, slim blue rectangular stem extends vertically down from the disk; its free tip rests on the tabletop. The entire module is a free body, not fixed to the table. The intended test is for one Panda to pinch the stem and lift the module clear, while the other grasps and turns the red knob.

The dial rotates only through physical finger contact. It has no actuator or hidden angle command. This folder contains an environment preview, not a policy task. `validation.json` covers five seconds of passive settling only.
